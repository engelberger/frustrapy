# Visualization surfaces

FrustraPy renders frustration on three surfaces. All three derive their classes and
colors from the same parsed FrustrationData table, so a user sees the same contacts and
the same coloring everywhere.

## Surfaces

- **PyMOL** `VisualizationScripts/{base}.pdb_{mode}.pml` — generated by
  `frustrapy/visualization/pymol_script.py`. For configurational/mutational it draws one
  `draw_links` cylinder per direct red/green contact between the two CA atoms and a
  `distance` object per water-mediated red/green contact. For single-residue it colors
  each residue's cartoon by class. Open with `pymol {base}.pdb_{mode}.pml` from the
  `VisualizationScripts/` directory (it `load`s the co-located `{base}.pdb` and `run`s
  the co-located `draw_links.py`).
- **ChimeraX** `VisualizationScripts/{base}.pdb_{mode}.cxc` (+ `.pb` for the contact
  modes) — generated by `frustrapy/visualization/chimerax_script.py`. The `.pb` file
  holds one pseudobond per red/green contact, colored by class; the `.cxc` opens the
  structure, shows the cartoon, and opens the `.pb`. For single-residue the `.cxc`
  colors residues by class directly. Open with `chimerax {base}.pdb_{mode}.cxc`.
- **Plotly** `Images/{base}_{mode}_classes.html` — `plot_frustration_classes` in
  `frustrapy/visualization/plots.py`. A class-colored figure with one trace per class
  (counts recoverable from the figure), plus the existing contact map and 5 Å density
  plots (with `graphics=True`).

## Class cutoffs

Configurational/mutational **contacts**: `FrstIndex <= -1` highly (red), `>= 0.78`
minimally (green), otherwise neutral (gray). Single-residue **plot** coloring:
`FrstIndex <= -1` highly (red), `>= 0.58` minimally (green), otherwise neutral (gray).
The 0.58 single-residue cutoff is intentionally distinct from the 0.78 contact cutoff;
see `frustrapy/core/constants.py`.

## Parity and consistency

The PyMOL generator is a reimplementation of the legacy
`frustrapy/core/scripts/GenerateVisualizations.pl`. The Perl script is no longer
invoked at runtime; it is kept as the byte-for-byte parity oracle. The Python `.pml` is
verified byte-identical to the Perl output on 1crn (configurational and mutational) and
on a synthetic multi-chain table that hits every draw branch
(`tests/test_visualization.py`).

The cross-surface consistency check asserts that the per-class contact/residue counts
agree across the `.pml`, `.cxc`/`.pb`, and the Plotly figure for all three modes.

## Rendering (maintainer step)

CI does not run PyMOL or ChimeraX. The generated scripts, selections, and colors are
asserted programmatically. To render, open the script in the respective application as
shown above.
